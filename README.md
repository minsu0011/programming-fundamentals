# 프로그래밍 기초 실습

2020년 ITE1014 입문 수업에서 작성한 Python과 C 과제입니다. 조건문, 반복문, 함수, 배열, 문자열과 포인터를 작은 프로그램으로 단계적으로 연습했습니다.

## 사용 기술

Python, C와 표준 라이브러리를 사용합니다. 외부 프레임워크 없이 입력을 읽고 계산한 뒤 출력하는 프로그램이 중심입니다.

## 폴더를 읽는 방법

`2-1`부터 `13-1`까지 실습 단위로 정리했습니다. 폴더 안의 문제는 독립적으로 실행합니다. 이름이 짧거나 번호인 파일은 입력·출력 부분부터 보면 목적을 파악하기 쉽습니다.

[6-2/5/elephant.py](6-2/5/elephant.py)에서는 조건을 나눠 값을 비교합니다. 작은 분기에서도 경계와 분기 순서가 결과를 어떻게 바꾸는지 확인하는 예제입니다. 전체 경로는 [소스 목록](docs/source-index.csv)에 있습니다.

## 학습 과정

입출력과 조건·반복에서 시작해 함수를 나누고 계산을 재사용하는 방식으로 옮겨 갔습니다. C의 배열·문자열을 다룰 때는 인덱스 범위와 메모리를 함께 생각해야 합니다.

과제마다 입력 규격과 시작점이 달라 하나의 application으로 합치지 않았습니다. 개별 프로그램을 실행하고 값을 바꿔 보는 학습 기록입니다.

## 실행

```bash
python 6-2/5/elephant.py
gcc path/to/exercise.c -o exercise
./exercise
```

입력은 각 소스의 `input`, `scanf` 또는 파일 열기 부분에서 확인합니다. 서로 다른 과제의 `main`을 함께 링크하지 않습니다.

기초 문법 과제이므로 공통 오류 처리나 자동 채점까지 제공하지는 않습니다. 과제와 starter의 출처는 [ATTRIBUTION.md](ATTRIBUTION.md)에 구분했습니다.
