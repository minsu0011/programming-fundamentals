# Programming Fundamentals
2020 ITE1014 입문 실습의 Python 31개와 C 37개 프로그램을 주차별로 정리한 저장소입니다. 원래 Hanyang course Git commit ancestry를 보존한 Laptop publication copy입니다.

## 학습 흐름
`2-1`부터 `13-1`까지의 실습 단위를 유지합니다. 표준입출력, 조건·반복, 함수, 배열/문자열과 포인터로 진행하는 작은 프로그램들을 독립적으로 읽고 실행합니다. 구체적인 source 경로는 [인덱스](docs/source-index.csv)를 참고하세요.

## 실행
Python은 해당 `.py`를 직접 실행하고, C는 main과 입력 형식을 확인해 개별 컴파일하세요. 서로 다른 주차의 main을 하나의 executable에 링크하지 않습니다. 원본 course server로 push하지 않으며 별도 GitHub publication remote를 사용합니다.

## 검증 및 한계
현재 환경에 native C compiler가 없어 전체 프로그램 실행은 미검증입니다. 파일 수나 과제 폴더 수를 독립 제품 수로 계산하지 않습니다. 원래 과제의 채점 결과가 제공되지 않은 파일은 정답성 UNKNOWN입니다.

과제 문제·교수자 starter의 재배포 범위가 확인되지 않아 private입니다. 원본 course directory와 Git history는 삭제하지 않습니다. 새 게시 커밋은 실제 현재 날짜를 사용합니다.
